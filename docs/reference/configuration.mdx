Gotenberg needs no configuration to start. Flags and environment variables tune it: every flag has a variable, so `--api-timeout` is `API_TIMEOUT`.

## Set a flag

Pass flags to the `gotenberg` command, which the image runs by default:

```bash
docker run --rm -p "3000:3000" gotenberg/gotenberg:9 \
  gotenberg --api-timeout=60s
```

Or set the variable instead, which suits Compose and Kubernetes:

```yaml title="compose.yaml"
services:
  gotenberg:
    image: gotenberg/gotenberg:9
    environment:
      API_TIMEOUT: 60s
      CHROMIUM_DENY_PRIVATE_IPS: "true"
```

- The variable wins when you set both.
- A list takes repeated flags, or comma-separated values: `CHROMIUM_DENY_LIST=^ftp:.*,^file:.*`.
- A duration takes a unit: `30s`, `5m`. A size takes one too: `5MB`, `1GB`.
