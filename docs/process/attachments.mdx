---
id: attachments
title: Attach files to PDFs
---

Embed files in a PDF: the source data, a spreadsheet, the XML of an e-invoice.

## Attach a file

<Request
  route="/forms/pdf/attach"
  files={["report.pdf", "invoice.xml"]}
  fields={{ file: "invoice.xml" }}
  output="report.pdf"
/>

The PDF lists the file under its name. `name` renames it, and `mimeType` overrides the type Gotenberg reads from the name.

## Attach several

One `attach` stage per file:

<Request
  route="/forms/pdf/pipe"
  files={["report.pdf", "invoice.xml", "logo.png"]}
  stages={[
    { op: "attach", file: "invoice.xml" },
    { op: "attach", file: "logo.png", name: "brand.png" },
  ]}
  output="report.pdf"
/>

## Mark an associated file

`relationship` makes the file a PDF/A-3 associated file, and says how it relates to the document: `Source`, `Data`, `Alternative`, `Supplement` or `Unspecified`.

<Request
  route="/forms/pdf/attach"
  files={["report.pdf", "invoice.xml"]}
  fields={{ file: "invoice.xml", relationship: "Data" }}
  output="report.pdf"
/>

A Factur-X invoice needs more than its XML: the [`remediate` stage](/docs/reference/stages#remediate) with the `Factur-X` profile embeds it and makes the PDF conform.

## List the attachments

<Request
  route="/forms/pdf/attachments"
  files={["invoice.pdf"]}
  response={{
    "invoice.pdf": [
      { name: "factur-x.xml", mimeType: "text/xml", relationship: "Data" },
    ],
  }}
/>

## Remove an attachment

<Request
  route="/forms/pdf/detach"
  files={["invoice.pdf"]}
  fields={{ name: "factur-x.xml" }}
  output="invoice.pdf"
/>

A name the PDF doesn't list answers 400, with the names it does list.
