---
id: forms
title: Fill and flatten forms
---

Fill the fields of a PDF form, then lock the values into the page. Works on any PDF: a PDF you upload, through the stage's own route or `/forms/pdf/pipe`, and a PDF a Chromium or LibreOffice conversion makes, through its `stages`.

## List the fields

<Request
  route="/forms/pdf/form"
  files={["fields.pdf"]}
  response={{
    "fields.pdf": [
      {
        name: "agree",
        type: "checkbox",
        value: "Off",
        pages: [1],
        states: ["Yes"],
      },
      {
        name: "color",
        type: "combo",
        value: "Red",
        pages: [1],
        options: ["Red", "Green"],
      },
    ],
  }}
/>

Each field comes with its fully qualified `name`, its `type`, its `value`, and the `pages` it sits on. `states` lists what a checkbox or a radio group takes besides `Off`, and `options` what a choice field takes. A PDF without a form answers `[]`.

## Fill the fields

<Request
  route="/forms/pdf/set-form"
  files={["fields.pdf"]}
  fields={{ fields: { agree: "Yes", color: "Green" } }}
  output="fields.pdf"
/>

`fields` keys each value by the field's name, as `/forms/pdf/form` lists them: `name`, or `address.city` for a field `city` inside a field `address`. A checkbox takes one of its states, a choice field one of its options. The fields stay editable.

## Select several items

A list that selects several takes an array:

<Request
  route="/forms/pdf/set-form"
  files={["multi.pdf"]}
  fields={{ fields: { tags: ["b", "c"] } }}
  output="multi.pdf"
/>

## Values a field can't hold

A value the field can't hold answers 400, and says what the field takes:

<Request
  route="/forms/pdf/set-form"
  files={["fields.pdf"]}
  fields={{ fields: { color: "Blue" } }}
  status={400}
  response={`HTTP/1.1 400 Bad Request
Content-Type: text/plain; charset=UTF-8

Stage 'set-form' failed on 'fields.pdf': value the form field cannot hold: "Blue" for field "color": "Blue" is none of its options: Red, Green`}
/>

A name the PDF doesn't have answers 400 too, with the names it has. Signature fields and push buttons take no value.

## Flatten the form

Fill the fields, then flatten them:

<Request
  route="/forms/pdf/pipe"
  files={["form.pdf"]}
  stages={[
    { op: "set-form", fields: { name: "Ada Lovelace" } },
    { op: "flatten-form" },
  ]}
  output="form.pdf"
/>

The values become part of the page. No reader can change them, and `/forms/pdf/info` answers `"formFields": false`.

## Forms from LibreOffice

LibreOffice exports a document's form fields as fields a reader can fill, unless [`exportFormFields`](/docs/reference/libreoffice#exportFormFields) is `false`. Add the `set-form` stage to the conversion to fill them in the same request.
