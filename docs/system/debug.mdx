title: Debug
---

Answers what Gotenberg runs: its modules, the versions of Chromium and LibreOffice, and the value of every flag.

<Endpoint path="/debug" />

The route is off until you set [`--api-enable-debug-route`](/docs/configuration#api-enable-debug-route), and answers 404 before:

<Request
  method="GET"
  route="/debug"
  run={false}
  response={{
    version: "9.0.0",
    timezone: "UTC",
    architecture: "amd64",
    modules: [
      "api",
      "chromium",
      "libreoffice",
      "libreoffice-api",
      "pdf",
      "webhook",
    ],
    modules_additional_data: {
      chromium: {
        version: "Chromium 156.0.8078.73 built on Debian GNU/Linux 13 (trixie)",
      },
      "libreoffice-api": { version: "LibreOffice 26.8.1.1 680(Build:1)" },
    },
    flags: {
      "api-body-limit": "",
      "api-port": "3000",
      "api-timeout": "30s",
      "chromium-max-concurrency": "6",
    },
  }}
/>

The answer lists every flag; the example shows four. It reveals your configuration, so keep the route away from the public: with [authentication](/docs/configuration#api-enable-basic-auth) on, it needs credentials like the other routes. Gotenberg doesn't log or trace it, unless [`--api-disable-debug-route-telemetry`](/docs/configuration#api-disable-debug-route-telemetry) is `false`.
