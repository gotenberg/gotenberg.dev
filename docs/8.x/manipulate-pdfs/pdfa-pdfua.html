PDF/A & PDF/UA

Converts one or more PDF files into PDF/A (archival) or PDF/UA (accessibility) format.

LibreOffice rasterizes table cells that carry a background color, which costs accessibility (Tables Rasterized to Images).

See the PDF Engines module configuration for engine selection flags.

LibreOffice Dependency

PDF/A and PDF/UA conversion relies on LibreOffice to re-process documents, which costs more CPU and RAM than simple merges or splits.

Basics​

POST/forms/pdfengines/convert
Headers
Gotenberg-Output-Filenamestring
The filename of the resulting file - Gotenberg automatically appends the file extension. Defaults to a random UUID filename.
Gotenberg-Tracestring
A custom request ID to identify the request in the logs; overrides the default UUID.
Form Fields
pdfaenum
Converts to a specific PDF/A archival standard. Options: PDF/A-1b, PDF/A-2b, PDF/A-3b, PDF/A-4.
pdfuaboolean
Enables PDF/UA (Universal Accessibility) compliance.
Default:false
Form Files
filesfile[]required
PDF files to convert.
Example Request
cURL
curl \
--request POST http://localhost:3000/forms/pdfengines/convert \
--form files=@/path/to/pdf.pdf \
--form pdfa=PDF/A-1b \
--form pdfua=true \
-o my.pdf
