title: Make PDF/A
---

Turn any PDF into an archival PDF/A, and check that it conforms.

## Convert to PDF/A

Add a `remediate` stage to a conversion:

<Request
  route="/forms/chromium/convert/html"
  files={["index.html", "style.css"]}
  stages={[{ op: "remediate", profile: "PDF/A-2b" }]}
  output="invoice.pdf"
  response={`HTTP/1.1 200 OK
Content-Type: application/pdf
Gotenberg-Remediation-Residual: 0
Gotenberg-Remediation-Rolled-Back: 0`}
/>

`Gotenberg-Remediation-Residual: 0` means the PDF conforms. Gotenberg answers 200 even when violations remain, so check the header.

## Check it

<Request
  route="/forms/pdf/validate"
  files={["invoice.pdf"]}
  fields={{ profile: "PDF/A-3b" }}
  response={{
    "invoice.pdf": { profile: "PDF/A-3b", compliant: true, violations: [] },
  }}
/>

A PDF that doesn't conform lists its violations, each with the clause it breaks.

## Where to go from here

- **Pick a level:** the letter and the number of `PDF/A-2b` say what the PDF keeps, and what it builds on: see [`remediate`](/docs/pdf/remediate#pick-a-pdfa-level). Pick the one your archive or portal asks for.
- **Any PDF:** [`/forms/pdf/remediate`](/docs/pdf/remediate) takes a PDF you already have.
- **Office documents:** LibreOffice writes PDF/A itself, with [`nativePdfa`](/docs/libreoffice/convert#make-it-archival).
- **E-invoices:** a Factur-X is a PDF/A-3 that carries its XML: see [Create Factur-X invoices](/docs/conformance/factur-x).
- **Accessible too:** one `remediate` stage takes a PDF/A profile and a PDF/UA one together, such as `["PDF/A-2b", "PDF/UA-1"]`: see [`remediate`](/docs/pdf/remediate#make-it-pdfa-and-pdfua). [Make accessible PDFs](/docs/conformance/accessibility) covers the tags.
