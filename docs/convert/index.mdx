Turn web pages, HTML, Markdown and office documents into PDF. Pick the route from what you have:

| You have                                                              | Route                                              | Engine      |
| :-------------------------------------------------------------------- | :------------------------------------------------- | :---------- |
| A web page's URL                                                      | `/forms/chromium/convert/url`                      | Chromium    |
| HTML, with its style sheets, images and fonts                         | `/forms/chromium/convert/html`                     | Chromium    |
| Markdown files                                                        | `/forms/chromium/convert/markdown`                 | Chromium    |
| Word, Excel, PowerPoint, OpenDocument and over a hundred more formats | `/forms/libreoffice/convert`                       | LibreOffice |
| Any of the first three, and you want an image                         | `/forms/chromium/screenshot/<url\|html\|markdown>` | Chromium    |

Chromium prints what a browser would show. LibreOffice lays the document out as the office suite would. Each engine has its own fields: [What works where](/docs/getting-started/what-works-where) compares them.

A conversion can go further in the same request: its `stages` field lists what to do with the PDF next, such as merge, stamp or sign. See [Process PDFs](/docs/process).
