---
id: url
title: Convert a web page to PDF
---

Print any page Chromium can reach, as a browser would.

## Send the URL

<Request
  route="/forms/chromium/convert/url"
  fields={{ url: "https://example.com" }}
  output="example.pdf"
/>

The URL starts with `http://` or `https://`. A `file://` URL answers 400: upload the HTML to [the HTML route](/docs/convert/html) instead.

## Log in

Send the cookies a session needs. Each takes a `name`, a `value` and a `domain`:

<Request
  route="/forms/chromium/convert/url"
  fields={{
    url: "https://example.com",
    cookies: [{ name: "session", value: "abc123", domain: "example.com" }],
  }}
  output="example.pdf"
/>

Or send a header, such as a token. End its value with `;scope=` and a regex, and Chromium sends it only to the URLs the regex matches, not to the third-party scripts the page loads:

<Request
  route="/forms/chromium/convert/url"
  fields={{
    url: "https://example.com",
    extraHttpHeaders: {
      Authorization: "Bearer abc123;scope=https://example\\.com/.*",
    },
  }}
  output="example.pdf"
/>

The value holds a `;`, so cURL sends it with `--form-string`: `--form` would cut it there. `userAgent` replaces Chromium's `User-Agent` header, for sites that answer bots differently.

## Fail on errors

A page that answers a 4xx or 5xx status fails the request with `409 Conflict`, rather than printing the error page. After a redirect, the status of the page it lands on counts:

<Request
  route="/forms/chromium/convert/url"
  fields={{ url: "https://example.com/missing" }}
  output="example.pdf"
  status={409}
/>

`failOnHttpStatusCodes` changes the statuses. The resources the page loads, failed loads and the console can fail the request too:

<Request
  route="/forms/chromium/convert/url"
  fields={{
    url: "https://example.com",
    failOnResourceHttpStatusCodes: [499, 599],
    failOnConsoleExceptions: true,
  }}
  output="example.pdf"
/>

`499` stands for every status from 400 to 499, and `599` for 500 to 599. The [page fields](/docs/reference/chromium#page-fields) list every check.

## Reach private addresses

Chromium reaches any address Gotenberg's network reaches, private ones included, such as `http://intranet.local/report`. Operators restrict it with [`--chromium-deny-private-ips`](/docs/configuration#chromium-deny-private-ips), [`--chromium-allow-list`](/docs/configuration#chromium-allow-list) and [`--chromium-deny-list`](/docs/configuration#chromium-deny-list). A blocked URL answers 403.
