title: Add headers and footers
---

Print a title, page numbers or a date on every page of a Chromium PDF. Works on the Chromium conversions: URL, HTML and Markdown. LibreOffice prints the headers and footers a document defines.

## Add a footer

Write the footer as its own small HTML file:

```html title="footer.html"
<!doctype html>
<html>
  <head>
    <style>
      .footer {
        margin: 0 2cm 0 auto;
        font-family: sans-serif;
        font-size: 9px;
      }
    </style>
  </head>
  <body>
    <p class="footer">
      Page <span class="pageNumber"></span> of <span class="totalPages"></span>
    </p>
  </body>
</html>
```

Upload it as `footer.html`, beside the page:

<Request
  route="/forms/chromium/convert/html"
  files={["index.html", "style.css", "footer.html"]}
  output="invoice.pdf"
/>

Chromium fills in the elements with these classes:

| Class        | Value                                            |
| :----------- | :----------------------------------------------- |
| `pageNumber` | The current page.                                |
| `totalPages` | The page count.                                  |
| `title`      | The page's `<title>`.                            |
| `date`       | The print date, as `11/1/26, 5:55 PM`.           |
| `url`        | The page's address, meaningful on the URL route. |

## Add a header

`header.html` works the same way, at the top of each page:

<Request
  route="/forms/chromium/convert/html"
  files={["index.html", "style.css", "header.html", "footer.html"]}
  output="invoice.pdf"
/>

## Style them

Chromium renders the header and footer apart from the page, with rules of their own:

- Set a font size. Without one, the text is about one point tall.
- Style them in a `<style>` tag. They don't load stylesheets.
- Embed images as data URIs, such as `src="data:image/png;base64,…"`. They don't load files.
- Give each its own class names. Chromium renders both in one document, so a rule in the footer reaches the header.

## Make room

The header and footer print inside the top and bottom margins, 0.39 inches by default. Widen them for a taller header:

<Request
  route="/forms/chromium/convert/html"
  files={["index.html", "style.css", "header.html", "footer.html"]}
  fields={{ marginTop: "1in", marginBottom: "1in" }}
  output="invoice.pdf"
/>
