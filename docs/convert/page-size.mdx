---
id: page-size
title: Set the page size and margins
---

Pick the paper, the orientation and the margins of a PDF.

## Pick a paper size

<Request
  route="/forms/chromium/convert/html"
  files={["index.html", "style.css"]}
  fields={{ paperSize: "A4" }}
  output="invoice.pdf"
/>

`paperSize` takes `A3`, `A4`, `A5`, `B4`, `B5`, `Letter`, `Legal` or `Tabloid`. Chromium prints on Letter without it.

## Turn it sideways

<Request
  route="/forms/chromium/convert/html"
  files={["index.html", "style.css"]}
  fields={{ paperSize: "A4", landscape: true }}
  output="invoice.pdf"
/>

## Set a custom size

`paperWidth` and `paperHeight` take a length: a number of inches, or a number with a unit, `mm`, `cm`, `in`, `pt`, `px` or `pc`:

<Request
  route="/forms/chromium/convert/html"
  files={["index.html", "style.css"]}
  fields={{ paperWidth: "210mm", paperHeight: "99mm" }}
  output="invoice.pdf"
/>

Next to `paperSize`, each overrides one side.

## Set the margins

<Request
  route="/forms/chromium/convert/html"
  files={["index.html", "style.css"]}
  fields={{
    marginTop: "2cm",
    marginBottom: "2cm",
    marginLeft: "1.5cm",
    marginRight: "1.5cm",
  }}
  output="invoice.pdf"
/>

Each margin is 0.39 inches by default. [Headers and footers](/docs/convert/headers-footers) print inside the top and bottom ones.

## Let the CSS decide

`preferCssPageSize` takes the size from your CSS `@page` rule, here `size: A5`:

<Request
  route="/forms/chromium/convert/html"
  dir="print"
  files={["index.html", "print.css"]}
  fields={{ preferCssPageSize: true }}
  output="handbook.pdf"
/>

Without it, Chromium takes the size from the fields, but keeps the orientation of the `@page` size: a portrait rule keeps the PDF portrait, over `landscape`.

## Fit the content on one page

`singlePage` prints the whole page on one page, as tall as the content, such as a receipt:

<Request
  route="/forms/chromium/convert/html"
  files={["index.html", "style.css"]}
  fields={{ singlePage: true }}
  output="receipt.pdf"
/>

`scale` shrinks or enlarges the content instead, from `0.1` to `2`.

## Office documents

LibreOffice takes the same `paperSize`, `paperWidth`, `paperHeight` and `landscape` fields:

<Request
  route="/forms/libreoffice/convert"
  files={["report.docx"]}
  fields={{ paperSize: "A4" }}
  output="report.pdf"
/>

Without them, each document keeps the page size it defines. Without `paperSize`, set both `paperWidth` and `paperHeight`, or neither. The margins come from the document.
