---
id: screenshots
title: Take screenshots
---

Capture a web page, your HTML or Markdown as a PNG, JPEG or WebP image.

## Capture a page

<Request
  route="/forms/chromium/screenshot/url"
  fields={{ url: "https://example.com" }}
  output="example.png"
/>

The image is 800 pixels wide and as tall as the page. The HTML and Markdown routes take the same files as [their PDF twins](/docs/convert/html).

## Pick the format

<Request
  route="/forms/chromium/screenshot/html"
  files={["index.html", "style.css"]}
  fields={{ format: "jpeg", quality: 80 }}
  output="invoice.jpeg"
/>

`format` takes `png`, the default, `jpeg` or `webp`. `quality` applies to JPEG.

## Size the window

`width` and `height` set the browser window, in CSS pixels. `clip` keeps that window only, instead of the whole page:

<Request
  route="/forms/chromium/screenshot/url"
  fields={{ url: "https://example.com", width: 1280, height: 720, clip: true }}
  output="example.png"
/>

## Capture one element

<Request
  route="/forms/chromium/screenshot/html"
  files={["index.html", "style.css"]}
  fields={{ selector: "h1" }}
  output="title.png"
/>

The image takes the bounds of the first element the CSS selector matches. No visible match answers 400.

## Sharpen it

`deviceScaleFactor` sets the image pixels per CSS pixel. At `2`, an 800 by 600 window gives a 1600 by 1200 image:

<Request
  route="/forms/chromium/screenshot/html"
  files={["index.html", "style.css"]}
  fields={{ deviceScaleFactor: 2, clip: true }}
  output="invoice.png"
/>

## Drop the background

`omitBackground` leaves the white default background out, so a PNG stays transparent where the page paints nothing:

<Request
  route="/forms/chromium/screenshot/html"
  files={["index.html", "style.css"]}
  fields={{ omitBackground: true }}
  output="invoice.png"
/>
