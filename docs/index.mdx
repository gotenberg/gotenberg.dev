Gotenberg is a Docker-based API for PDF. It converts web pages and office documents to PDF, then merges, stamps, signs, remediates and delivers them.

## Run it

Gotenberg ships as a Docker image. Start it with one command:

```bash
docker run --rm -p "3000:3000" gotenberg/gotenberg:9
```

Then send it a request. This one prints a web page to PDF:

<Request
  route="/forms/chromium/convert/url"
  fields={{ url: "https://example.com" }}
  output="example.pdf"
/>

Gotenberg needs no configuration to start. Flags tune it for production when you get there.
