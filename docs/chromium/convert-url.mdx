Prints any page Chromium can reach, as a browser would.

<Endpoint path="/forms/chromium/convert/url" />

## Send the URL

<Request
  route="/forms/chromium/convert/url"
  fields={{ url: "https://example.com" }}
  output="example.pdf"
/>

The URL starts with `http://` or `https://`. A `file://` URL answers 400: upload the HTML to [the HTML route](/docs/chromium/convert-html) instead.

<Url route="/forms/chromium/convert/url" output="example.pdf" />
