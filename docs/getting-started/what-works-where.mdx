Which route takes which feature. A field name in `code` is a form field of the route. A stage name, such as `stamp-text`, goes in the route's `stages` field, or, on a single-stage route, is the route itself: `/forms/pdf/stamp-text`.

## Conversion routes

| Feature                             | Chromium PDF                                          | Screenshots         | LibreOffice                                           |
| :---------------------------------- | :---------------------------------------------------- | :------------------ | :---------------------------------------------------- |
| Input                               | A URL, HTML or Markdown                               | The same            | Office documents, over a hundred formats              |
| `files`, `archives`, `downloadFrom` | Yes                                                   | Yes                 | Yes                                                   |
| `stages`                            | Yes, on the printed PDF                               | No                  | Yes, on the exported PDFs                             |
| Webhooks                            | Yes                                                   | Yes                 | Yes                                                   |
| `Gotenberg-Output-Filename`         | Yes                                                   | Yes                 | Yes                                                   |
| Paper size, orientation             | `paperSize`, `landscape`, `paperWidth`, `paperHeight` | `width`, `height`   | `paperSize`, `landscape`, `paperWidth`, `paperHeight` |
| Margins                             | `marginTop` and the others                            | No                  | The document's own                                    |
| Headers, footers, page numbers      | `header.html`, `footer.html`                          | No                  | The document's own                                    |

| Pick pages                          | `nativePages`, or `select`                            | No                  | `nativePages`, or `select`                            |

## Two ways to the same result

A field whose name starts with `native` asks the engine to do the work while it makes the PDF. A stage does it afterwards, the same way on every route. [How Gotenberg works](/docs/about#native-field-or-stage) says which to pick.

## An uploaded PDF on a conversion

A conversion's stages see only the PDFs the conversion makes. To bring in a PDF you upload, name it in a stage that reads a file, such as [`insert`](/docs/process/pages#insert-pages) or [`stamp-pdf`](/docs/process/stamps#stamp-a-letterhead). On the LibreOffice route, a PDF no stage names goes through LibreOffice like any document.
