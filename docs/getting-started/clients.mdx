---

Gotenberg is an HTTP API that takes `multipart/form-data`, so any HTTP library talks to it. A client adds types and file handling on top.

## PHP

[gotenberg/gotenberg-php](https://github.com/gotenberg/gotenberg-php) is the official client. Version 3 follows the Gotenberg 9 API, with its stages and renamed fields; version 2 stays on Gotenberg 8. Its README covers the upgrade.

## Other languages

The [Awesome Gotenberg](https://github.com/gotenberg/awesome-gotenberg#clients) list gathers the community's clients. Each follows Gotenberg at its own pace: check that it supports Gotenberg 9 and its [stages](/docs/pdf/pipe).

## Without a client

Every request in these docs is a cURL command you can copy, and [How requests work](/docs/getting-started/requests) covers what a wrapper needs. Gotenberg's repository also ships a [Bruno collection](https://github.com/gotenberg/gotenberg/tree/main/.bruno), with a request for every route.
