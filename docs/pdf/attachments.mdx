Lists the files embedded in a PDF.

<Endpoint path="/forms/pdf/attachments" />

<Request
  route="/forms/pdf/attachments"
  files={["invoice.pdf"]}
  response={{
    "invoice.pdf": [
      {
        name: "factur-x.xml",
        mimeType: "text/xml",
        relationship: "Alternative",
      },
    ],
  }}
/>

Each file comes with its name, and with its media type and its relationship to the document when the PDF states them. [`attach`](/docs/pdf/attach) embeds files, [`detach`](/docs/pdf/detach) removes one by the name listed here, and [`extract-attachments`](/docs/pdf/extract-attachments) returns it.
