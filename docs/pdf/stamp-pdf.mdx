## Stamp a letterhead

<Request
  route="/forms/pdf/stamp-pdf"
  files={["report.pdf", "letterhead.pdf"]}
  fields={{ source: "letterhead.pdf" }}
  output="report.pdf"
/>

Draw the letterhead on a transparent page, so the content under it shows: Chromium makes one from HTML with `printBackground` and `omitBackground`. `scale` resizes the page, and `sourcePage` picks another page of the source.
