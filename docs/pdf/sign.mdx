Signs a PDF with your certificate, so readers can check who signed it and that nothing changed since.

<Endpoint op="sign" />

Upload the PDF, a PEM certificate and its private key:

<Request
  route="/forms/pdf/sign"
  files={["report.pdf", "cert.pem", "key.pem"]}
  fields={{
    certificate: "cert.pem",
    key: "key.pem",
    reason: "Approved",
    location: "Paris",
  }}
  output="report.pdf"
/>

`reason`, `location`, `contactInfo` and `name` show in the viewer's signature panel. `cert.pem` is a self-signed test certificate, so viewers flag the signature as untrusted: sign with a certificate from an authority they trust.

## Sign with a PKCS#12 file

A `.p12` or `.pfx` file holds the certificate and its key. `certificatePassword` opens it:

<Request
  route="/forms/pdf/sign"
  files={["report.pdf", "cert.p12"]}
  fields={{ certificate: "cert.p12", certificatePassword: "secret" }}
  output="report.pdf"
/>

## Make it PAdES

`pades: true` makes a PAdES signature, the format the EU's eIDAS regulation recognizes for electronic signatures. Set it for documents signed in or for the EU:

<Request
  route="/forms/pdf/sign"
  files={["report.pdf", "cert.pem", "key.pem"]}
  fields={{ certificate: "cert.pem", key: "key.pem", pades: true }}
  output="report.pdf"
/>

## Timestamp the signature

`timestampUrl` asks an RFC 3161 timestamp authority to vouch for the signing time:

<Request
  route="/forms/pdf/sign"
  files={["report.pdf", "cert.pem", "key.pem"]}
  fields={{
    certificate: "cert.pem",
    key: "key.pem",
    pades: true,
    timestampUrl: "http://timestamp.digicert.com",
  }}
  output="report.pdf"
/>

Operators decide which authorities Gotenberg may call: see [`timestamp`](/docs/pdf/timestamp#pick-the-authorities).

## Sign last

A change after a signature breaks it, so only a `timestamp` or a `render` may follow the `sign` stage, and a list signs once. Process before you sign: a stage that rewrites the file, such as `select`, `merge`, `remediate` or `optimize`, refuses a signed PDF, since its rewrite would drop the signature. Stamps, rotations, metadata, bookmarks, attachments and tags append to the file and keep it: see [what each stage does to the file](/docs/pdf/pipe#what-each-stage-does-to-the-file). An encrypted PDF signs in two requests: decrypt it, then sign the result.

<Request
  route="/forms/pdf/pipe"
  files={["report.pdf", "cert.pem", "key.pem"]}
  stages={[
    { op: "optimize" },
    { op: "sign", certificate: "cert.pem", key: "key.pem", pades: true },
  ]}
  output="report.pdf"
/>
