Convert to PDF.

Chromium prints a URL, HTML or Markdown. LibreOffice converts Word, Excel, PowerPoint and over a hundred other formats.

  • URL
  • HTML
  • Markdown
  • Office documents
Chromium · /forms/chromium/convert/url
curl \
--request POST http://localhost:3000/forms/chromium/convert/url \
--form url=https://example.com \
-o example.pdf

29 stages on any PDF.

Merge, split, stamp, sign, encrypt, redact. List them in the stages field: Gotenberg runs them in order, on a PDF or right after a conversion.

  • Pipe stages
  • Every route
  • Sign a contract
litho · /forms/pdf/pipe
curl \
--request POST http://localhost:3000/forms/pdf/pipe \
--form files=@report.pdf \
--form files=@annex.pdf \
--form 'stages=[
{ "op": "merge" },
{ "op": "set-metadata", "title": "Q3 report" },
{ "op": "remediate", "profile": "PDF/A-4" },
{ "op": "optimize" }
]' \
-o archive.pdf

Validate, then remediate.

Checks a PDF against PDF/A, PDF/UA and Factur-X, clause by clause. Remediation repairs it until it conforms and reports what it couldn't fix.

  • Validate
  • Remediate
  • Autotag
  • Archive documents
litho · /forms/pdf/validate
curl \
--request POST http://localhost:3000/forms/pdf/validate \
--form files=@report.pdf \
--form profile=PDF/UA-1

Factur-X, ZUGFeRD, XRechnung.

Send the invoice with its Cross-Industry Invoice XML. One remediate stage returns a PDF/A-3 hybrid invoice.

  • E-invoice from HTML
  • Remediate
  • Attachments
LibreOffice · /forms/libreoffice/convert
curl \
--request POST http://localhost:3000/forms/libreoffice/convert \
--form files=@invoice.docx \
--form files=@invoice.xml \
--form 'stages=[
{ "op": "remediate", "profile": "Factur-X", "xml": "invoice.xml", "level": "EN 16931" }
]' \
-o invoice.pdf

Straight to your bucket.

Gotenberg fetches the source from a presigned URL and answers 204. Once the work is done, it uploads the PDF to your bucket, then posts an event.

  • Webhooks
  • Upload results to S3
  • Headers
LibreOffice · /forms/libreoffice/convert
curl \
--request POST http://localhost:3000/forms/libreoffice/convert \
--form 'downloadFrom=[
{ "url": "https://bucket.s3.amazonaws.com/in.docx?X-Amz-Signature=…" }
]' \
--header 'Gotenberg-Webhook-Url: https://bucket.s3.amazonaws.com/out.pdf?X-Amz-Signature=…' \
--header 'Gotenberg-Webhook-Method: PUT' \
--header 'Gotenberg-Webhook-Events-Url: https://api.example.com/events'
